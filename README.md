# AI HealthCare Assistant

AI HealthCare Assistant adalah proyek orisinal untuk membangun pendamping kesehatan digital yang membantu pengguna memahami informasi kesehatan, menyiapkan konsultasi, dan mengelola perjalanan kesehatan secara lebih terarah.

## Visi

Membangun layanan kesehatan digital yang **aman, mudah dipahami, dan berpusat pada manusia**. Sistem AI digunakan sebagai pendamping informasi, bukan pengganti tenaga kesehatan.

## Versi saat ini

Versi pertama adalah situs web publik yang berisi:
- Beranda produk AI HealthCare Assistant.
- Panduan awal untuk menuliskan keluhan kesehatan.
- Penanda sederhana untuk kondisi yang berpotensi memerlukan perhatian segera.
- Rancangan layanan janji temu.
- Rancangan catatan kesehatan.
- Prinsip keselamatan dan privasi.

Fitur yang belum terhubung ke server ditandai sebagai fitur yang sedang dibangun. Versi demo ini **tidak memberikan diagnosis medis** dan tidak meminta data medis sensitif.

## Prinsip pengembangan

1. Produk dan kode dikembangkan untuk proyek ini, bukan sebagai fork produk lain.
2. Data kesehatan diperlakukan sebagai data sensitif.
3. AI tidak boleh menyatakan diagnosis pasti tanpa proses klinis yang sesuai.
4. Fitur darurat harus mengarahkan pengguna ke layanan medis nyata.
5. Infrastruktur awal diusahakan tanpa biaya agar mudah dikembangkan dan diuji.
6. Setiap fitur baru harus melalui pengujian sebelum digunakan.

## Teknologi awal
- React
- GitHub Actions
- GitHub Pages untuk situs publik versi awal

Arsitektur backend, autentikasi, penyimpanan data, AI, audit, dan integrasi layanan kesehatan akan dibangun bertahap setelah fondasi frontend stabil.
