# SehatKita Admin Center

Aplikasi administrasi SehatKita yang dipisahkan dari website pengguna.

## Arsitektur
- `react-app/` — website pengguna SehatKita.
- `admin-app/` — Admin Center, UI dan build terpisah.
- Admin tidak memiliki menu di website pengguna.
- Admin tidak menggunakan data pasien nyata pada versi demo.

## Target pemisahan berikutnya
Repository khusus Admin: `AI-HealthCare-Assistant-Admin`.

Repository baru membutuhkan pembuatan repository GitHub dari akun pemilik sebelum source dapat dipindahkan secara otomatis.
